## ✨ Features

| Feature | Detail |
|---|---|
| 🌌 **3D Space Background** | 15,000 moving coloured stars + procedural spaceship orbiting the scene |
| 🤖 **Byte — AI Guide Robot** | Speaking robot that explains each section in a male voice (Web Speech API) |
| 📸 **Profile Photo** | Animated hero avatar with glowing rings and floating tech badges |
| 🎞️ **Smooth Scrolling** | Lenis butter-smooth scroll (lerp 0.07) + GSAP ScrollTrigger parallax |
| 🃏 **3D Card Tilt** | Every bento/cert card tilts with mouse movement (elastic snap-back) |
| 📱 **100% Responsive** | 5 breakpoints · safe-area insets · landscape phone mode · reduced-motion |
| ⚡ **GPU Composited** | `will-change: transform` + `backface-visibility: hidden` — zero jank |
| 🔊 **Voice Narration** | Per-section male-voice narration auto-triggers on scroll |

## 🛠️ Tech Stack

- **Three.js r134** — 3D galaxy, starfield, procedural spaceship
- **GSAP 3.12 + ScrollTrigger** — scroll-linked animations, parallax, stagger
- **Lenis 1.1.14** — butter-smooth scroll engine
- **Vanilla CSS** — custom design system, glassmorphism, elastic transitions
- **Web Speech API** — browser-native TTS for Byte robot narration
- **GitHub Pages** — hosting
