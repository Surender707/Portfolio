## 👨‍💻 About The Project

Welcome to my personal developer portfolio! This site is designed to be an immersive, interactive showcase of my journey, technical skill set, and projects spanning **Machine Learning, Deep Learning, Computer Vision, and Modern Full-Stack Web Development**.

Rather than a static resume page, I wanted to build an engaging cinematic experience that combines real-time 3D graphics, fluid physics-based animations, and responsive UI components.

### 🌟 Key Highlights

- **🌌 3D Interactive Starfield & Galaxy**: Custom Three.js particle simulation featuring over 25,000 stars with dynamic depth, rotation, and procedural elements that react smoothly to user input.
- **🤖 Byte — The Interactive AI Guide**: An interactive desktop companion built with the browser Web Speech API that walks visitors through each section of the portfolio with real-time text typewriter effects.
- **⚡ Physics-Based Smooth Scrolling**: Integrated **Lenis** smooth scroll engine coupled with **GSAP ScrollTrigger** for seamless parallax effects and sticky card interactions.
- **📱 Responsive & Accessible**: Crafted to deliver 60 FPS performance across all viewports—from ultrawide monitors to mobile devices—with support for reduced motion preferences.
- **🧱 Modern React 19 + TypeScript**: Modularized component architecture for clean state management, strong type safety, and blazing fast Vite-powered builds.

## 🚀 Getting Started

To run this portfolio locally on your machine, follow these steps:

### Prerequisites
- Node.js (v18.0 or later recommended)
- npm or yarn

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Surender707/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the site with HMR.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Lint and code quality checks:**
   ```bash
   npm run lint
   ```
